Step 0: Input validation (runs before everything, intentionally, even if a gate would apply)
mass_kg for both animals must be finite and greater than 0. Any bite_force_n used in a comparison must be finite and greater than 0. Otherwise throw a clear validation error naming the animal and field. Never return NaN, Infinity, or a fallback result.

Step 1: Function check
- An animal can function if the environment is in its functions_in.
- Neither can: indeterminate, deciding_factor null, advantage_score null.
- One cannot: realistic, no_contest, deciding_factor null. forced_fight, the other animal favored, deciding_factor environmental_advantage. advantage_score null in both.

Step 2: Behavior check (realistic only; skip in forced_fight)
- reluctant(x) = x.temperament === "avoids" || x.fighting_style === "bluff"
- aBacksOff = reluctant(a) && b.temperament !== "aggressive"
- bBacksOff = reluctant(b) && a.temperament !== "aggressive"
- If either is true: no_engagement with animals = every animal that backs off (one or both). deciding_factor behavior, advantage_score null.

Step 3: Factors
- Size: value = 0.8 * (log2(a.mass_kg) - log2(b.mass_kg)). Reason example: "Hippopotamus outweighs Lion about 7.9 to 1."
- Bite force comparison: only when both bite_force_n values are non-null AND both field_sources.bite_force_n tiers are non-null AND equal. Then value = 0.5 * (log2(a.bite_force_n) - log2(b.bite_force_n)). Otherwise value 0, reason "Not compared: bite-force values are missing or have different source tiers." This is a source-tier filter, not a guarantee the measurements used the same method, and it compares bites to each other, not bites against defenses.

Step 4: Decide
- advantage_score = sum of factor values.
- >= 0.5: A favored. <= -0.5: B favored. Otherwise even (no decisive advantage on the scored factors).
- deciding_factor fighting_ability when favored, null when even.
- Comment: with bite excluded, an animal needs about a 1.54x mass advantage to be favored.

Step 5: Evidence quality
Count tiers of every field consulted:
- functions_in for both, always
- temperament and fighting_style for both, when the behavior check ran (tier null if no field_sources entry)
- mass_kg for both, when factors ran
- bite_force_n for both, only when compared
Null counts as lower tier. Share of tier 1 or 2 at 2/3 or more: mostly_higher_tier. 1/3 or less: mostly_lower_tier_or_unknown. Otherwise mixed.
